# SQL Query Generator (SQLAi)

An AI-powered web app that converts natural language questions into SQL queries. Paste your database schema (`CREATE TABLE` statements), type a question in plain English (e.g., "Get all users who signed up this month"), and get a ready-to-use SQL query generated by an LLM.

## Features

- **Natural language → SQL** — generates SQL from plain-English questions using a code-generation LLM (`defog/llama-3-sqlcoder-8b`) via the Hugging Face Inference API
- **Schema parser** — analyzes pasted schemas to extract table/column info and surface warnings (e.g., missing primary keys)
- **Input validation** — server-side middleware validates schema and question format/length before calling the AI
- **Query history** — sidebar that tracks previously generated queries
- **Quick-start examples** — one-click templates for common scenarios (e-commerce orders, analytics, student records)
- **Dark/light theme toggle** and **copy-to-clipboard** for the generated SQL
- **Syntax-highlighted output** for readability

## Tech Stack

- **Backend**: Node.js, Express.js
- **Templating**: EJS
- **Frontend**: HTML5, CSS3, Bootstrap 5, Vanilla JavaScript
- **AI/LLM Integration**: Hugging Face Inference API (`defog/llama-3-sqlcoder-8b` — text-to-SQL model)
- **Syntax Highlighting**: Highlight.js
- **Other**: dotenv (environment config), custom middleware (input validation), regex-based schema parsing

## Getting Started

1. Install dependencies:
   ```
   npm install
   ```
2. Create a `.env` file in the project root with:
   ```
   HF_TOKEN=your_huggingface_api_token
   API_URL=https://router.huggingface.co/v1/chat/completions
   PORT=8080
   ```
3. Start the server:
   ```
   node index.js
   ```
4. Open `http://localhost:8080` in your browser.

## Usage

1. Paste your database schema (`CREATE TABLE` statements) into the schema box.
2. Type your question in plain English.
3. Click **Generate SQL Query** to get the corresponding SQL.
